# 🪄 Quick Start: AI Auto-Complete

## For Kids (No API Key Needed!)

### Step 1: Turn on Demo Mode
1. Tap the **gear icon** ⚙️ (top-left of dashboard)
2. Find "AI AUTO-COMPLETE" section
3. Turn ON **"Demo-Modus"**
4. Tap **"Fertig"**

### Step 2: Try It Out!
1. Tap the **"+" button** to add a card
2. Type: **Sonne**
3. Tap the **🪄 AI button** (purple/pink)
4. Watch the magic! ✨
   - English: "sun"
   - Example: "Die Sonne scheint hell."
5. Tap **"FERTIG"** to save

### Step 3: Add More Cards!
Try these words (Demo Mode knows them):
- Mond (moon)
- Stern (star)
- Apfel (apple)
- Hund (dog)
- Katze (cat)
- Haus (house)
- Baum (tree)
- Blume (flower)
- Auto (car)

## For Parents (With API Key)

### Step 1: Get OpenAI API Key (5 minutes)

1. Go to: **https://platform.openai.com**
2. Click **"Sign up"** (or login)
3. Go to **"API Keys"** section
4. Click **"Create new secret key"**
5. **Copy** the key (starts with `sk-proj-...`)
6. **Important**: Save it somewhere safe!

### Step 2: Add API Key to App

1. Open FlashcardApp
2. Tap **gear icon** ⚙️
3. Turn **OFF** "Demo-Modus"
4. Paste your API key in the text field
5. Look for green checkmark: ✅ "API-Schlüssel aktiv"
6. Tap **"Fertig"**

### Step 3: Test It!

1. Tap **"+"** to add card
2. Type **any German word** (not just the 10 demo words!)
3. Tap **🪄 AI**
4. Get real translation + example from ChatGPT!

## 🐛 Troubleshooting

### "AI button doesn't appear"
- Did you type a German word?
- Is it at least 2 letters?

### "Orange error message shows"
- Check your internet connection
- If using API key, verify it's correct (starts with `sk-`)
- Try Demo Mode instead

### "It's taking forever"
- Normal response time: 1-3 seconds
- If >10 seconds, check internet
- Try again or use manual entry

### "I want to edit AI's suggestion"
- Just tap the field and type!
- AI just fills it in, you can change anything

## ❓ FAQ

**Q: Is Demo Mode good enough?**  
A: For testing, yes! For daily use with varied vocabulary, get API key.

**Q: Can I use my own examples instead of AI's?**  
A: Absolutely! Just edit the example field after AI fills it.

**Q: What if AI gives wrong translation?**  
A: Fix it! AI is smart but not perfect. Always review and edit.

**Q: Can siblings share one API key?**  
A: Yes! One key per family is fine. Cost is per card, not per user.

**Q: Do I need internet always?**  
A: For AI features, yes. But reviewing cards works offline!

**Q: Can I turn off AI later?**  
A: Of course! Just turn on Demo Mode or type manually anytime.
