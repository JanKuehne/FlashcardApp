# Quick Start Guide: Adding Vocabulary Cards

## 🎯 For Kids (Age 8-10)

### How to Add New Words

1. **Open the app** - You'll see the Dashboard

2. **Tap the blue "+" button** (top-right corner)

3. **Type the German word**
   ```
   Example: Sonne
   ```

4. **Type the English word**
   ```
   Example: sun
   ```

5. **Type an example sentence** (optional)
   ```
   Example: Die Sonne scheint.
   ```

6. **Choose what to do next:**
   - Tap **"SPEICHERN & WEITER"** if you have more words to add
   - Tap **"FERTIG"** if you're done

---

## 📝 For Parents

### When to Use This Feature

**✅ Perfect for:**
- Daily homework vocabulary
- Adding words from textbook chapters
- Preparing for vocabulary tests
- When kids encounter new words

**❌ Not ideal for:**
- Bulk importing 100+ words (use CSV later)
- Adding vocabulary you don't understand (LLM feature coming)

---

### Tips for Success

1. **Start small** - Add 5-10 words the first session
2. **Make it routine** - Add words right after homework
3. **Use examples** - They help with context and memory
4. **Review quickly** - Study new cards within 24 hours

---

### Keyboard Shortcuts

- **German field** → Press "Next" → moves to English
- **English field** → Press "Next" → moves to Example
- **Example field** → Press "Done" → saves card (if both fields filled)
