## 🤔 Decision Points

### Decision 1: API Key or Mock Mode?

**Stick with Mock if:**
- Kids mostly need common words (Sonne, Mond, etc.)
- You want zero setup
- Testing phase (1-2 weeks)

**Upgrade to API if:**
- They need varied vocabulary
- They love the AI feature
- $0.02/month is fine with you

**My recommendation**: Try mock for 1 week, decide then.

---

### Decision 2: Daily Goal Setting?

Current default: **20 cards**

**Lower to 10 if:**
- Kids are new to German
- They're struggling with current deck
- You want them to focus on quality

**Raise to 30-50 if:**
- They're flying through 20 easily
- They have big test coming up
- They're competitive and want challenge

**How to change**: Settings → Daily Goal slider

---

## 🎓 Tips for Parents

### Homework Integration Strategy

**Don't:**
- ❌ Force them to use it
- ❌ Micromanage their card creation
- ❌ Punish for not using it

**Do:**
- ✅ Make it available
- ✅ Demonstrate once
- ✅ Let them discover benefits
- ✅ Praise when they use it
- ✅ Gamify: "Who has highest streak?"

### Success Patterns

**Pattern 1: Immediate Addition**
```
Teacher assigns vocabulary
→ Kid adds cards same day
→ Reviews that evening
→ Reviews next morning
→ Quiz day: confident!
```

**Pattern 2: Weekly Batch**
```
Sunday evening: Homework planning
→ Add all week's vocabulary (20-30 cards)
→ Review daily (5 min/day)
→ By Friday: all memorized
```

**Pattern 3: Competitive Siblings**
```
Twin A adds 10 cards
Twin B adds 12 cards
Both review daily
Track streaks on dashboard
Winner gets extra dessert 🍰
```

## 🐛 Common Issues & Solutions

### "The AI button doesn't show up"
**Solution**: Type a German word first (at least 2 letters)

### "AI says error: Network unavailable"
**Solution**: Check internet, or switch to manual entry

### "I typed wrong word, how do I fix it?"
**Current**: Delete card and re-add (editing coming later)  
**Workaround**: Just add corrected version

### "Can we add Spanish too?"
**Answer**: Yes! But not built yet. For now, focus on German.

### "It's not saving my API key"
**Solution**: Make sure key starts with `sk-` and tap "Fertig"
