## 🎓 Why This Matters

### Educational Logic:

1. **Practice the Foreign Language**
   - Kids see English word in context
   - Learn how to USE the English word
   - Build English sentence comprehension

2. **Proper Language Learning**
   - Flashcard front: German (native)
   - Flashcard back: English (learning)
   - Example: English (practice!)

3. **Real-World Usage**
   - Kids need to understand English sentences
   - Examples show word usage in English
   - Prepares them for English reading

### Example Card:

```
┌─────────────────────────────────┐
│ Front (German): Hund            │
│ Back (English): dog             │
│ Example: The dog barks loudly.  │ ← in English!
└─────────────────────────────────┘
```

When reviewing:
1. See "Hund" → recall "dog"
2. Check back → yes, it's "dog"
3. Read example → "The dog barks loudly"
4. Understand how to use "dog" in English
